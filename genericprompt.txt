how to return:

Top-level format:
{
  "title": "Quiz title",
  "description": "Short description",
  "questions": []
}

Question types:

multi-choice: one correct option.
{
  "type": "multi-choice",
  "text": "Question?",
  "options": ["A", "B", "C", "D"],
  "correct": 1,
  "points": 1
}

multi-answer: multiple correct options, shown as checkboxes.
{
  "type": "multi-answer",
  "text": "Question?",
  "options": ["A", "B", "C", "D"],
  "correct": [0, 2],
  "points": 2
}

matching: dropdown match rows.
{
  "type": "matching",
  "text": "Match each item",
  "matches": [
    {"prompt": "Item 1", "options": ["A", "B", "C"], "correct": 0},
    {"prompt": "Item 2", "options": ["A", "B", "C"], "correct": 2}
  ],
  "points": 2
}

fill-gap: inline text blanks. Each {key} needs an answer.
{
  "type": "fill-gap",
  "text": "The {word_1} class retrieves data.",
  "answers": {"word_1": "Timelines"},
  "points": 1
}

Formatting supported in question text, options, matching prompts, and matching answers:

Inline code:
"text": "What does `git status` show?"

Code blocks:
"text": "What is printed by this code?\n```js\nconsole.log(2 + 2);\n```"

Inline maths:
"text": "Solve \\(x^2 = 16\\)."

Display maths:
"text": "Which rule is shown here?\n\\[ a^2 + b^2 = c^2 \\]"

You may also use $$...$$ for display maths:
"text": "Differentiate:\n$$ f(x) = x^3 + 2x $$"

Rules:
- Use double quotes and valid JSON only.
- Escape LaTeX backslashes in JSON strings. For example, write \\(x^2\\), not \(x^2\).
- Use \n inside JSON strings when a code block or display equation needs line breaks.
- Wrap code blocks with triple backticks and an optional language name, such as ```js.
- Use inline code with single backticks for commands, variables, and short snippets.
- Use \\(...\\) for inline maths and \\[...\\] or $$...$$ for display maths.
- Use zero-based indexes for "correct".
- Base every question on the supplied content.
- Use plausible distractors.
- Award partial-credit-friendly points where practical.
- Fill-gap answers are case-insensitive in the app.
